나라장터 입찰공고를 조건별로 모아 보고 투찰을 준비하세요

나라장터 입찰공고

ⓘ
투찰은 나라장터에서 직접 하셔야 합니다. 이 화면은 공고 조회와 투찰 준비까지만 담당합니다. 나라장터 전자입찰은 사업자용·개인용 인증서로 본인 신원확인을 거치도록 설계돼 있어, 프로그램이 대신 투찰하도록 만들면 인증서 관리 의무 위반이자 입찰방해·부정당업자 제재(입찰참가자격 제한) 대상이 될 수 있습니다. 공고를 고르고 금액을 정하는 일까지 여기서 끝내고, 마지막 투찰 버튼만 나라장터에서 누르시면 됩니다.

🔧 딱 한 가지만 해주시면 됩니다

나라장터에서 공고를 받아오려면 GitHub 저장소에 API 키를 한 번 등록해 주셔야 합니다. 등록해 두시면 이후로는 한 시간마다 자동으로 공고를 받아옵니다. 프로그램을 따로 설치하거나 다른 서비스에 가입하실 필요는 없습니다.

  1. 공공데이터포털에서 조달청_나라장터 입찰공고정보서비스 활용신청 → 일반 인증키 (Decoding) 복사
  2. 저장소 시크릿 등록 화면을 열고 이름에 G2B_SERVICE_KEY, 값에 복사한 키를 넣고 저장
  3. 수집 워크플로에서 Run workflow 를 눌러 첫 수집 실행 (1~2분)

활용신청 직후에는 키가 아직 활성화되지 않아 실패할 수 있습니다. 보통 30분~1시간 걸립니다.
